Aggiornamento **Rama Edit 0.2.5 per Windows**.

Il pulsante **Impostazioni macchine** è ora ancorato in fondo alla barra laterale sinistra. Rimane in basso anche quando si ridimensiona la finestra o si cambia pagina.

Scaricare **RamaEdit-Setup-0.2.5-x64.exe**, chiudere Rama Edit e installare sopra la versione precedente. I dati locali e le configurazioni macchina vengono conservati.

Versione di prova non firmata digitalmente.
