Aggiornamento **Rama Edit 0.2.16 per Windows**.

- Pulsante **Apri** più largo, con freccia a destra per gli **ultimi 20 file aperti**. Il clic su Apri continua ad aprire la finestra di scelta dei file.
- Nel menu dei recenti compaiono nome del file e cartella. La lista viene conservata dopo la chiusura dell’app; riaprire un file già in una scheda riattiva quella scheda, mantenendo le modifiche non salvate. Disponibile **Svuota lista**.
- Aggiunta una **X in alto a destra** nello stato di trasmissione al termine dell’invio, anche dopo interruzioni o errori. La X chiude completamente il riquadro, che si apre nuovamente al prossimo invio.
- Verifiche automatiche Windows per il menu dei recenti, riapertura, modifiche non salvate, file non disponibili, salvataggio della lista e chiusura dello stato di trasmissione.

Scaricare **RamaEdit-Setup-0.2.16-x64.exe**, chiudere Rama Edit e installare sopra la versione precedente. Programmi e impostazioni vengono conservati.

Versione di prova non firmata digitalmente.
